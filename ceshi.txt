
# 4. 和 AI 全栈的层级对应

你的原始 AI 全栈里，3 层是 CUDA/ROCm、算子库、Profiling、Kernel Fusion，4 层是 Triton/CUDA Kernel、图优化、Memory Planning、ExecutionPlan IR，5 层是 PyTorch/vLLM/SGLang/TensorRT-LLM 等训练与推理 Runtime，8 层包含 Evidence/Replay，10 层包含 Agent/Harness，13 层包含 Benchmark、Regression、Rollback、Audit。Triton-agent 只切这些层，不再强行覆盖 0–13 全部。

```text id="bbnj3y"
Triton-agent 实际覆盖层级
├── 3. AI 系统软件层
│   └── Triton 算子、Profiling、Benchmark、Kernel Fusion 基础
│
├── 4. 编译器与执行优化层
│   └── Triton Compile、模板变体、MicroRL/Bandit、自优化搜索
│
├── 5. 训练与推理 Runtime 层
│   └── PyTorch wrapper、vLLM/SGLang mock adapter，后置真实集成
│
├── 8. Evidence / Replay 层
│   └── episode、leaderboard、shape-specific config、replay.py
│
├── 10. Agent 与 Harness 层
│   └── generate、compile、verify、profile、repair、select、promote
│
└── 13. 评测 / 治理 / 回滚层
```

# 7. Reward / Score 设计

第一阶段不做大规模 PPO，只做 MicroRL / Bandit 级轻量优化。

```python id="vk7c02"
score = 0.0

if compile_pass:
    score += 0.2

if verify_pass:
    score += 0.6
else:
    score -= 1.0

if speedup >= 1.05:
    score += min(0.5, speedup - 1.0)

if variance > 0.10:
    score -= 0.2

if memory_peak > baseline_memory * 1.10:
    score -= 0.2

if has_nan_or_inf:
    score -= 1.0
```

注意：

```text id="89cm2z"
这里有 reward，但不是 CUDA Agent 那种大规模强化学习。
v0/v1 只是用 reward 做候选选择和 Bandit 更新。
```

# 9. 第一阶段算子优先级

```text id="p5mhb7"
P0:
  RMSNorm
  RoPE
  fused_bias_gelu

P1:
  SwiGLU

P2:
  KV Append

  QuantMatMul
  Paged KV
```

原因：

```text id="tvdsq1"

P3 才进入高难度推理核心路径。
```

# 10. CLI 设计

```bash id="hdkqzv"

triton-agent init rmsnorm

# 优化某个 shape
triton-agent optimize rmsnorm --shape B=8,T=2048,D=4096 --dtype fp16 --device cuda

# 查看排行榜

triton-agent replay episodes/rmsnorm/000042
```
